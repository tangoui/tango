# GPU 渲染 里程碑 2（全部操作原生化 + 局部重绘）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `paint.List` 的全部操作在 GPU 上原生绘制（不再每帧 CPU 光栅化补丁），并支持局部重绘与滚动平移，使参考配置下 CPU 提交 ≤ 2 ms、编辑器整帧 ≤ 4 ms。

**Architecture:** 在同一个 quad 着色器里按 `Kind` 增加描边（含虚线）、阴影、渐变（线性/径向/锥形，色带纹理）、棋盘格、图片（着色器内 Catmull-Rom）；`FillPath` 走 CPU 覆盖率蒙版缓存进 R8 图集；不透明度组渲染到离屏层再合成；仿射变换中平移+缩放原生、旋转/斜切回退补丁。每种新图元的覆盖率/颜色公式写成 Go 参考函数，`paint.CPU` 与着色器共用同一公式（规格 6.8 允许改 CPU 并重录黄金图），用网格相等测试锁定。局部重绘：`paint.List` 新增可选的 `Damage` 与 `ScrollRegion` 提示，渲染器在常驻离屏目标上只重画脏区、平移已有像素。

**Tech Stack:** Go 1.27、自研 Go 着色器编译器（`ui/shader`）、Metal（purego）。

**Spec:** `docs/specs/gpu-renderer.md`（里程碑 2；6.1、6.2、6.3、6.6、6.8）；里程碑 1 验收记录 `docs/specs/gpu-renderer-m1-report.md`（第 4 节的性能缺口）。

## Global Constraints

- 模块 `github.com/tangoui/tango`，Go 1.27，桌面无 cgo，不新增外部依赖。
- 颜色按预乘 alpha、sRGB 空间混合，与 `paint.CPU` 一致；比对阈值：几何与填充每通道 ≤ 2；文字与图片缩放 ≤ 4；超阈值像素 ≤ 0.5%。
- 每种新的 GPU 图元必须有 Go 参考函数，`paint.CPU` 调用同一函数（或逐运算相同的副本），并有"着色器参考函数 == paint 函数"的网格相等测试（≤ 1e-6），模式同 `paint.RRectCoverage` / `TestPaintRRectCoverageMatchesShader`。
- 着色器布局：uniform 与实例结构禁止 Vec3 / int；改结构后必须 `go generate ./ui/gpu/gen/`（`TestGeneratedUpToDate`、`quad_layout.go` 断言把关）；继续用单个 quad 着色器加 `Kind`，不新开着色器包。
- **文件归属（与其他会话的约定）：** `ui/paint`、`ui/text` 现在可以改，但必须保留：`GlyphRasterizer` 及 1px 透明边、蒙版已含 gamma；`cpu.go` 中 `glyph()` 的引擎分支、`BeginFrame(scale)`、`RenderRegion` 不推进 gen；`ui/golden_test.go` 关闭系统文字引擎。重录 `ui/testdata/*.png` 前必须用 Read 查看新旧图并在报告中描述差异来自预期的公式变化。`ui/runner.go`、`ui/window.go` 由另一会话的无障碍 agent 正在修改——**Task 9 必须等控制者确认窗口开放后才开始**；`Window.Present` 只能用新增可选接口扩展，不改现有签名。`uihost/**`、`internal/platform/**` 不改。
- **不提交 git**（提交由会话 min-a6 统一做）。每个任务结束时 `ui/gpu/**`、`ui/shader/**`、`ui/paint/**` 必须可编译，`go vet` 在 darwin/linux/windows 干净。
- 不打开 `~/go/pkg/mod/github.com/egoist/mygo`。
