# 终端组件 M1（普通 shell）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做出能在 Tango 自绘窗口里跑本地 shell 的终端组件：纯 Go 模拟器（解析器、网格、回滚、SGR、光标与擦除、传统按键编码）、只认字节流的视图（绘制、局部重绘、选区复制粘贴、滚动、输入法）、桌面三平台本地 PTY，以及 `ClaimEscape` 前置改动和示例程序。

**Architecture:** `ui/terminal/vt` 是不依赖 `ui` 的模拟器：`Parser` 把字节变成动作，`Terminal` 执行动作维护 `Screen`（行环形缓冲 + 回滚），`EncodeKey` 把 `input.KeyEvent` 变成字节。`ui/terminal` 的 `Terminal` 持有 `vt.Terminal`、一把锁和读 `Conn` 的 goroutine；`View` 是 `ui.Custom` 组件，按行合并同样式的格排版绘制，只对脏行发 `Damage`。`sys/pty` 用 `/dev/ptmx` 与 ConPTY 实现 `terminal.Conn`。

**Tech Stack:** Go 1.27；`ui`（即时模式，`ui.Custom` / `ui.State` / `Box.Focusable`）、`ui/text`（`Style.Mono`）、`ui/paint`、`ui/input`、`ui/theme`；`golang.org/x/sys/unix`、`syscall`（Windows）；开发工具 Node + `@xterm/headless`（仅生成参考快照）。

**Spec:** `docs/specs/terminal.md`（4.1–4.5、6 的 M1 一行、7、7.1、10）

## Review Focus

1. 程序输出被拆在两次 `Read` 之间的多字节 UTF-8 字符和转义序列（如 `\x1b[3` | `1m`、`中` 的三个字节分两次到达）：显示与一次到达完全一样 —— Task 2 `TestParserSplitAcrossWrites`、Task 4 `TestTerminalSplitUTF8`。
2. 宽字符写到行末最后一格（只剩一格放不下两格宽的字符）：换到下一行开头，最后一格留空，与 xterm.js 一致 —— Task 3 `TestWideCharAtRightEdge`。
3. 大量输出时用户已向上滚动查看回滚：视口不跟着跳，新行进回滚，用户回到底部才跟随；回滚满时最旧行被淘汰而视口指向的内容不错位 —— Task 3 `TestScrollbackViewportStableOnOutput`、`TestScrollbackEvicts`。
4. 子进程退出（shell 里敲 `exit`）：读循环收到 EOF 后终端进入已结束状态、视图显示退出提示、不 panic、goroutine 不泄漏 —— Task 7 `TestTerminalConnEOF`、Task 9 `TestPTYExitStatus`。
5. 粘贴包含 `\x1b[201~` 的文本（括号粘贴结束标记）：标记被去掉，不能伪造按键 —— Task 6 `TestPasteStripsBracketEnd`。

```go
// Handler 接收解析出的动作。参数切片只在调用期间有效。
type Handler interface {
	Print(r rune)                 // 单个可打印码点（非 ASCII 快路径之外的）
	PrintASCII(b []byte)          // 快路径：连续可打印 ASCII（0x20–0x7E）
	Execute(b byte)               // C0 / C1 控制字符
	CSI(p *Params, inter []byte, final byte, private byte) // private: '?', '>', '<', '=' 或 0
	ESC(inter []byte, final byte)
	OSC(data []byte)              // 不含 ST / BEL；超过 1 MB 截断丢弃
	DCS(p *Params, inter []byte, final byte, data []byte) // 整段收齐后一次回调（M1 只需不出错）
}
type Params struct{ /* 最多 32 个参数，每个最多 8 个子参数 */ }
func (p *Params) Len() int
func (p *Params) Get(i, def int) int       // 缺省或 0 时返回 def
func (p *Params) Sub(i int) []int          // i 的子参数（':' 分隔），含主值
type Parser struct{ /* 状态、缓冲 */ }
func NewParser(h Handler) *Parser
func (p *Parser) Write(b []byte)           // 可被任意切分地多次调用
```
