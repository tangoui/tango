# GPU 渲染 里程碑 3（Windows Direct3D 11 + HLSL 后端）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Tango 自绘 UI 在 Windows 上经 Direct3D 11 渲染：着色器编译器新增 HLSL（SM 5.0）后端，`ui/gpu/d3d11` 实现与 Metal 设备同一帧契约的 `gpu.Device` 与呈现器；本机只能交叉编译与静态检查，Windows 实机运行列为待补。

**Architecture:** `ui/shader/hlsl` 从同一份 IR 输出 HLSL，`tanshader` 同时生成 `quad.metal` 与 `quad.hlsl`；`ui/gpu/d3d11` 用 `syscall` + 手写 COM vtable 调用 D3D11/DXGI（无 cgo），运行时用系统自带 `d3dcompiler_47.dll` 编译嵌入的 HLSL；设备语义（上传、批次、图层池、局部帧、拷贝、错误）以 `ui/gpu/metal/metal_darwin.go` 顶部设计注释为准。平台侧（canvas 交出 HWND、uihost 选择渲染器）按 M1 的分工由会话 min-a6 实现，本计划提供契约文档与 `d3d11.NewPresenter`。

**Tech Stack:** Go 1.27、`syscall`（Windows）、D3D11 / DXGI 1.2（flip model）、`d3dcompiler_47.dll`、自研着色器编译器 `ui/shader`。

**Spec:** `docs/specs/gpu-renderer.md`（里程碑 3；6.3、6.4、6.5、6.6、6.8、第 7 节）；M2 验收记录 `docs/specs/gpu-renderer-m2-report.md`。

## Global Constraints

- 模块 `github.com/tangoui/tango`，Go 1.27；桌面无 cgo；**不新增外部依赖**（只用标准库 `syscall`，不把 `golang.org/x/sys` 升为直接依赖）。
- 颜色按预乘 alpha、sRGB 空间混合，与 `paint.CPU` 一致；比对阈值：几何与填充每通道 ≤ 2；文字与图片缩放 ≤ 4；超阈值像素 ≤ 0.5%。
- 帧契约（`ui/gpu/frame.go`：`Frame`、`Batch`、`Upload`、`ImageUpload`、`CopyRegion`、`LayerDesc`、`Retainer`、`PixelReader`）不改语义；D3D11 设备的行为必须与 Metal 设备逐条一致（以 `metal_darwin.go:22-100` 的设计注释为规范），差异写进报告。
- 着色器：继续单个 quad 着色器加 `Kind`；改结构后 `go generate ./ui/gpu/gen/`；uniform 与实例结构禁止 Vec3 / int。
- 着色器字节码获得方式（规格第 7 节二选一，**本计划决定**：运行时用系统 `d3dcompiler_47.dll` 的 `D3DCompile` 编译嵌入的 `quad.hlsl`，因为本机没有 Windows 生成环境）；编译失败返回带编译器日志的错误，由调用方回退 CPU。
- **文件归属：** 不改 `internal/platform/**`、`uihost/**`（平台接口与 uihost 胶水由 min-a6 实现，见 Task 7）；不改 `ui/paint`、`ui/text`、`ui/runner.go`、`ui/window.go`；`ui/gpu/metal` 只做 Task 1 列出的改动；不得 import `internal/platform/windows`（可参照其 COM 调用写法自写）。
- **不提交 git**（提交由会话 min-a6 统一做）。每个任务结束时 `go build ./... && go vet ./...` 在 darwin 通过，`GOOS=windows GOARCH=amd64` 与 `GOOS=windows GOARCH=arm64` 的 `go build ./... && go vet ./ui/... && go test -c -o /dev/null ./ui/gpu/d3d11/` 通过，`GOOS=linux go build ./...` 通过。
- 不打开 `~/go/pkg/mod/github.com/egoist/mygo`。
- Windows 专属代码的构建标签：`//go:build windows && (amd64 || arm64)`；其他平台的桩返回 `ErrUnsupported`。
- 测试：能在 darwin 跑的（HLSL 生成、布局、vtable 槽位与结构体尺寸常量）必须在 darwin 跑；需要真实 D3D11 的测试放 `_windows_test.go`，本计划内只要求交叉编译通过，实机运行列为待补。

## Review Focus

1. 没有硬件显卡的 Windows（虚拟机、远程桌面、CI）：自动用 WARP 软件设备，画面与 CPU 一致 —— Task 3 `TestNewDeviceFallsBackToWARP`。
2. 运行中显卡被移除或驱动重置（TDR、驱动更新）：`Execute`/`present` 返回包装 `gpu.ErrDeviceLost` 的错误，不 panic，之后的调用都返回错误 —— Task 4 `TestDeviceRemovedIsLost`、Task 6 `TestPresenterDeviceRemoved`。
3. 窗口最小化（尺寸 0）与超大窗口（> 16384 设备像素）：最小化时不调用 `ResizeBuffers`、不提交；超大时返回包装 `gpu.ErrTargetTooLarge` 的错误且不算故障 —— Task 4 `TestTargetTooLarge`、Task 6 `TestPresenterZeroSize`。
4. 系统缺少 `d3dcompiler_47.dll` 或 HLSL 编译失败：`NewDevice` 返回包含编译器日志的错误，不 panic —— Task 3 `TestCompileErrorIncludesLog`。
5. uniform 结构在 HLSL cbuffer 打包规则下与 Go 布局不同（字段跨 16 字节边界）：生成器报带位置与两边偏移的错误 —— Task 2 `TestHLSLLayoutMismatch`。
