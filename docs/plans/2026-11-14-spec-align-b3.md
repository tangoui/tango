## Global Constraints

与第 1 批计划的 Global Constraints 逐条相同（worktree、实施 agent 不提交、作者 `tango <903300326@qq.com>` 不加 Co-Authored-By、精确值读源码、功能并集一套 API、默认值走令牌/Defaults 不按 Flavor 分支、默认值不符直接改并写 CHANGELOG 草稿、稳定层只增、去重、缺基础能力写「暂不做，缺 X」、新代码英文文档中文文案走 Locale、Ant 外观除规范修正外不变）。本批另加：

- **去重**（AUTHORING §13、§14；设计 §7.1）：shadcn Sonner = `Message`/`Notification`；Spinner = `Spin`；Sheet 与 shadcn Drawer（vaul）= `Drawer`；Dialog = `Modal`；AlertDialog = `Confirm`；HoverCard = `Popover.Trigger("hover")`；Resizable = `Splitter`；EP Loading = `Loading`；EP MessageBox = `MessageBox`/`Confirm`/`Prompt`；antd `FloatButton.BackTop` = `BackTop`。**不新增同义入口**；NavigationMenu、Sidebar 见「已定事项」。
- **v6 改名**（新增新名方法，旧方法加 `// Deprecated: use X.`，不删）：Steps `direction`→`orientation`、`labelPlacement`→`titlePlacement`、`progressDot`→`type: "dot"`、`items[].description`→`content`；Alert `message`→`title`、`closeText/closeIcon/onClose/afterClose`→`closable{…}`；Notification `message`→`title`、`btn`→`actions`；Modal `maskClosable`→`mask.closable`、`destroyOnClose`→`destroyOnHidden`、`focusTriggerAfterClose`→`focusable.*`；Dropdown `dropdownRender`→`popupRender`、`destroyPopupOnHide`→`destroyOnHidden`、`Dropdown.Button` 弃用（用 `Compact`+`Dropdown`+`Button`）；Splitter `layout`→`orientation`、`collapsible.icon`；Spin `tip`→`description`；Breadcrumb `routes`→`items`；FloatButton `description`→`content`。
- **comp-\* 分支**：shell（`StatusBar`、`TitleBar`、`NotificationCenter`）与 dock 正由另一会话并入 main。`page_titlebar.go`、`titlebar.go`、`notification_center.go`、`statusbar.go`、`dock*.go` 只读；Menubar 被 TitleBar 使用，改 Menubar 时 TitleBar 页外观不能坏。rebase 后 origin/main 改过本组文件的，以对方为准再适配，不回退。
- Ant 主题之外的改动不得改变 Ant 主题截图。
- 计时类行为（Message/Notification 时长与悬停暂停、Spin `delay`、HoverCard 延迟、Tour/Modal 动效）测试用 `Driver` 的时钟推进，不 `time.Sleep`。
