# GPU 渲染 里程碑 1（Go 着色器编译器骨架 + macOS Metal）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Tango 自绘 UI 在 macOS 上经 Metal 渲染上屏，着色器用 Go 语法写一次、由自研编译器生成 MSL，结果与 CPU 渲染按阈值一致。

**Architecture:** `ui/shader`（sl 运行库 → front 解析/类型检查 → ir → msl 后端，`tanshader` 生成器）把 `ui/gpu/shaders` 里的 Go 着色器编译成 `ui/gpu/gen/*.metal`。`ui/gpu` 把 `paint.List` 变成设备无关的 `Frame`（批次 + 纹理上传），由 `gpu.Device` 执行：`ui/gpu/metal`（真 GPU）与 `ui/gpu/cpuexec`（在 CPU 上直接执行同一份 Go 着色器，用于无 GPU 测试）。里程碑 1 原生支持 FillRect（含圆角）、PushClip（含圆角）、Text（字形图集）、Pop；其余操作经"CPU 补丁"回退（`paint.CPU` 把该操作画成小图上传为纹理），保证 gallery 全部能画。

**Tech Stack:** Go 1.27、`go/parser` + `go/types`、purego v0.11.1（`github.com/ebitengine/purego/objc`）、Metal / QuartzCore。

**Spec:** `docs/specs/gpu-renderer.md`（里程碑 1，及 6.1、6.4、6.5、6.6、6.8）

## Global Constraints

- 模块 `github.com/tangoui/tango`，Go 1.27，桌面无 cgo；不新增外部依赖（purego 已在 go.mod）。
- 不照搬 mygo（`~/go/pkg/mod/github.com/egoist/mygo@*` 不得打开阅读）；前端用 `go/types`、IR 为结构化 IR。
- 颜色按预乘 alpha、sRGB 空间混合，与 `paint.CPU` 一致。
- 比对阈值：几何与填充每通道差 ≤ 2；文字与图片缩放 ≤ 4；超阈值像素 ≤ 0.5%。
- `TANGO_RENDERER=cpu` 强制 CPU；GPU 初始化失败自动回退 CPU。`tan dev` 维持 CPU。
- GPU 只支持不透明 canvas。
- **不提交 git**（用户未授权提交；仓库尚无任何提交）。每个任务结束跑 `go build ./... && go vet ./...`（含 `GOOS=windows`、`GOOS=linux` 交叉编译）确认没有破坏其他平台。
- 其他会话可能同时修改本仓库（darwin 后端去重重写等）。只改本计划列出的文件；改共享文件（`ui/paint/cpu.go`、`internal/platform/canvas.go`、`internal/platform/darwin/canvas*.go`、`uihost/*`）时先 `git diff` / 读最新内容，增量修改，不整文件覆盖。
- 规格修订：规格 6.4 写的构建标签 `tangoshader` 改为"着色器包是普通包（无构建标签）；运行时只引用其中的数据类型（如 `Instance`），着色器函数只被生成器、CPU 执行器与测试调用"（这样 CPU 执行测试能直接调用；未被调用的函数链接时被裁掉）；Task 5 顺手更新规格该句。

## Review Focus

1. 窗口缩放（Retina 2x ↔ 外接 1x 屏之间拖动）：drawableSize 与图集按新 scale 失效重建，画面不模糊、不错位 —— Task 9 的 `TestMetalScaleChange`。
2. 空帧与零尺寸（窗口最小化、宽或高为 0）：Render 不报错、不提交命令 —— Task 6 `TestRenderZeroSize`、Task 8 `TestMetalZeroSize`。
3. 不平衡的 Push/Pop、超深嵌套裁剪（>32 层）：与 CPU 一样容错，不 panic —— Task 6 `TestUnbalancedPop`、`TestDeepClip`。
4. 字形图集写满：超过一页时新开页、LRU 淘汰后仍能正确显示（大字号 CJK 文本）—— Task 7 `TestAtlasOverflow`。
5. GPU 不可用（无设备 / 着色器编译失败）：自动回退 CPU 且窗口仍正常显示 —— Task 9 `TestFallbackOnDeviceError`。
