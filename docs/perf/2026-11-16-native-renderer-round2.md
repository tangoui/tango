# macOS 原生渲染第二轮：CPU、文字存储与实测

本轮保留大窗口 GPU 默认，继续优化显式 `TANGO_RENDERER=native` 的路径。
不改变组件 API、Ant Design 6.7 / Pro v6 外观基线、字体选择或基准应用代码。

## 改动

- 文字图层保留小幅尺寸变化所需的底层位图，超过当前墨迹面积四倍时收缩。
  实际绘制仍按精确可见区域裁剪；64 MiB 位图预算按最坏保留容量计算。
- 相邻、位于同一行的原生文字合并为一个图层：最多八段，合并面积不超过
  总墨迹面积两倍；保留每段颜色、裁剪、绘制顺序和独立持有的字形数据。
  非文字绘制命令是合并边界。整数移动继续复用内容。

## 测量方法

Apple M4、macOS 26.6、Go 1.27.3、CGO=0，相同发布参数
`-buildvcs=false -trimpath -ldflags "-s -w"`。优化前固定 Tango `1274788`；
优化后生产代码为 `2164e53`（`7525553` 只补充审查测试）。
NSGo 固定 `2449cc530e72bec3c0f1329890cf744ef1e563b6`。
本轮包含 main 新近的 CPU 裁剪、字形与 Metal 资源改进，不能把它们归为本轮收益。

三个场景各做三轮交错运行，偶数轮反转顺序；行情和列表增加优化前原生对照。
确认首帧后稳定三秒，再测十秒；另对三个后端各做一次 62 秒列表采样。
合计 33 次短跑和 3 次长跑。逐秒检查锁屏与后台测试负载；测试进程 CPU
达到单核 25% 时拒绝该轮。全部接受轮次的测试进程 CPU 为零、窗口未锁屏。
计时中没有强制 GC、截图或 CPU profile；物理 footprint 使用十进制 MB，
应用 CPU 为单核百分比，帧间隔是回调时间，不能等同实际呈现 FPS。

工作桌面仍有远程控制、编辑器和 WindowServer 背景负载；未关闭用户应用。
WindowServer 每次先测三秒静息值，再记录同窗增量，因此该增量有系统背景噪声。

## 未采用的数字

早期启用 CPU profile 的单次诊断曾得到原生行情约 12%、列表约 7%。
无 profile 的交错计时未复现该幅度，因此不把它们作为收益或验收数字。
先前锁屏时没有首帧的近零 CPU 数据也仍然无效。

## 正确性与验证

- 本轮行情和列表的真实原生图层图像已检查，所有可见文字、40 行行情、
  正负值颜色和滚动行号完整。
- 保留位图：小幅尺寸变化不重新分配尺寸、极短替换收缩、1/1.5/2 倍缩放、
  裁剪缩小时旧墨迹清除、64 MiB 最坏容量预算及完整回退。
- 文字批次：颜色、独立裁剪、整数移动复用、借用字形改变、绘制顺序边界、
  大空白不合并；半透明重叠与分开图层在三个缩放下进行像素对照。
  故意颠倒批次顺序时对照失败（49 vs 16），恢复后通过。
- 独立审查无 Critical 或已确认的生产缺陷；提出的半透明重叠覆盖缺口已补齐。
- 完整生产/开发根模块测试通过，CPU 密集包串行；gallery short、CLI、vet、
  相关 race，以及 Linux/amd64、Windows/amd64、Intel macOS 交叉构建通过。
  交叉构建不等于目标硬件运行覆盖。
- 当前源码的真实 macOS 原生窗口再次通过原有 33 项调度、输入/IME、缩放、
  调整大小、空闲、关闭检查，加四项原生检查；拥有的图层像素另行检查。
- gallery 采用 CI short 范围；完整多主题文字对比长跑不在本轮覆盖内。

## 决策与代价

1. 保留位图上限四倍并计入预算：少做尺寸重建，可能增加位图内存或提前软件回退。
2. 同行批次最多八段、空白不超过两倍：减少图层，变动一段时可能重绘未变化邻段。
3. 半透明对照允许两级 8 位合成取整差异；没有放宽既有 CPU/Metal 测试容差。
4. 保留大窗口 Metal 默认：CPU 和尾部验收尚未支持全面切换，代价是默认大窗口
   暂时仍有较高 Metal 驻留。
5. 审查按只读方式进行，运行验证由执行者承担，避免与计时相互干扰；其他硬件
   只能在相应构建/运行覆盖范围内判断。
