# HTML 分词：减少匹配和捕获分配

基线 `7cfcc4f67b289425403fc424d2e2a250932e64b9`，分支 `perf/all-modules-20261116`。本批延续 HTML 性能优化，不修改 HTML grammar，不关闭内嵌 JavaScript/CSS。证据目录：`/Users/admin/min/outputs/tango-html-perf-20261116/`。

## 结果和验收边界

本轮五对诊断中，混合 HTML 每文档分配次数中位数从 32,272 降至 16,886，减少 47.7%；分配字节从 2,256,466 降至 1,315,976，减少 41.7%。这是自身前后的分配结果，不能等同为速度提升 47.7%，也不能等同为领先 MyGo。

本轮尚未通过“比 MyGo 强 50%”的耗时验收。双方统一 Go 1.27.3、CGO_ENABLED=0、Darwin arm64，参考固定 MyGo v0.9.0、同一 37,200 字节输入，跨文档复用 token 容量。测量采用新进程、串行、交替顺序；所有正式候选要求前后 1 分钟负载 <6，且至少五对合格样本。当前候选负载为 11.58–16.22，全部超标，合格对数为零，`accepted_ns_op` 均为空；原始耗时保留在日志中，不据此发布速度百分比或新的 MyGo 耗时倍数。上批的合格基线与接口差异见 [第四批报告](2026-11-16-modules-batch4.md)。

## 实现

- 从已翻译、已锚定的 RE2 AST 推导保守的 ASCII 首字符集合，排除必不匹配的规则。可空和零宽条件不作激进排除，Unicode 与不支持形式保持原引擎处理。
- 简单 ASCII 字符集合、字面量和贪婪重复采用有界匹配计划。变长重复必须与后续所有可空 atom 及第一个必需 atom 的集合不相交，才能避免回退；歧义、复杂选择、非贪婪和断言回原引擎。源码限 512 字节、计划限 64 个 atom。
- 动作不读取子组时只获取整体匹配区间，复用当前递归调用的两个索引槽。cases、group、动态 token 和状态替换保守保留完整捕获；公共完整捕获 API 的结果仍由调用者独立拥有。
- 工作量与行预算入口保留；回溯的超时确认和累计耗时确认保留。没有全局共享 scratch，也没有复制 MyGo 的生产分词代码。

收益主要在热匹配路径。额外 AST 分析和计划在编译时创建，大小有上界；本批没有证明冷编译时间或整个编辑器启动时间改善。

## 分配诊断

每场景重复对应片段 200 次，旧/新各五轮。表中均为均摊 B/op、allocs/op 的跨轮中位数；`matrix-raw.json` 保存命令、cwd、负载、二进制 SHA、迭代数和全部结果，`matrix-summary.json` 保存范围和资格筛选。高负载下回溯的慢匹配确认重试会带来小幅分配波动，因此同时保留范围，不把诊断中位数当作固定开销保证。

混合场景分配次数范围：旧 32,225–32,378，新 16,875–16,892；分配字节范围：旧 2,254,117–2,262,993，新 1,314,924–1,319,107。所有有监测的旧/新 HTML 轮次均为 0 timeouts/op、0 degraded/op，包含另行进行的五对 MyGo 诊断。MyGo 该语料报告 2,200 allocs/op，仍明显少于当前 Tango；两者 token 格式、语法覆盖等 API 能力不完全相同，不代表功能等价。

## 正确性和检查

- 失败回归实测：HTML 文本一行原为 3 次分配，未使用的属性子组原为 4 次，均超过 2 次预算；优化后两项通过。见 `html-red.txt` 和相关测试日志。
- 原生 RE2 对照覆盖约 61,000 组模式/flags/输入组合，包括歧义重复、锚点、空匹配、Unicode 折叠、非法 UTF-8、捕获结果所有权和不支持/超长模式；保留回溯超时错误的新增测试也通过普通及 race 检查。
- 旧/新固定二进制的全部语言 fixture 和生成输入共 24,881 条记录逐字节一致；专门的 HTML 混合、畸形、跨行、MIME、script/style 和 4,000 组生成输入共 12,024 条记录逐字节一致。比较包括 token 类型、UTF-16/字节偏移、State、LineInfo 及已有目标切片前缀。见 `differential-all.json`、`differential-html.json`。
- 初次 race 检查暴露旧 `TestSlowLineDegrades` 的速度假设：原无捕获规则在新路径连续三次约 142–145ms 完成，低于 race 构建 500ms 预算，故无需降级；旧版约 506–569ms 时降级。测试现用等价的组动作强制完整捕获 RE2 慢路径，连续三次约 545–558ms 正确降级；原普通构建 200ms 断言和所有生产预算未放宽。无捕获路径仍由既有 fake-clock 测试检查预算。原失败与对照日志完整保留。
- regex、monarch、highlight、buffer 普通测试通过；调整上述测试后的四包 race 全部通过。race 使用其必须的 CGO_ENABLED=1，与正式性能二进制区分。两次独立静态审查（生产实现及后续测试修订）均未发现确认问题。
- 全项目/CLI 的 `go test -p 1 ./... ./cmd/tan/... -count=1 -timeout=10m` 通过，131 个包通过、40 个包无测试，见 `full-tests.txt`；全项目/CLI `go vet -p 1 ./... ./cmd/tan/...` 通过。最终 gofmt、diff 检查及测量源码/二进制 SHA 核对通过，见 `checks-final.json`。

基线 overlay 的生产源码已逐文件与基线提交核对；旧/新/MyGo 二进制工具链与 SHA、当前源码 SHA 见 `source-manifest.json` 及各 `.buildinfo.txt`。下一步仍需低负载耗时复测；继续压缩 CSS/JS 回溯匹配、嵌入状态和通用规则调度成本，不能用本批分配改善宣布 MyGo 目标完成。
