# `tan mcp` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 `tan` 加 `mcp` 子命令：一个 MCP 服务器，让 AI 代理操作 Tango 项目（检查、诊断、新建、生成、构建、打包、开发模式）和运行中的 Tango 应用界面（语义树、查找、动作、输入、截图、WebView 选择器操作）。

**Architecture:** 现有自动化客户端（`automation` 包，绑定 `testing.TB`）的连接、启动、等 token 文件、构建开发版、WebView JS 片段抽到主模块内部包 `internal/automation/client`，`automation` 包改为基于它、对外 API 不变。`cmd/tan` 新增 `mcp*.go`：用官方 Go MCP SDK 注册工具；项目工具以子进程方式运行 tan 自身并放进后台任务；界面工具通过 `client` 启动或连接开发构建，转发到现有自动化协议 `internal/automation`。

**Tech Stack:** Go 1.27；`github.com/modelcontextprotocol/go-sdk` v1.8.0（只进 `cmd/tan/go.mod`）；现有 `internal/automation` 协议；`examples/ledger`（自绘）与 `examples/hello`（WebView）做端到端。

**Spec:** `docs/superpowers/specs/2026-11-19-tan-mcp-design.md`

## Global Constraints

- MCP 服务器代码和 MCP SDK 依赖只在 `cmd/tan` 模块；tango 主模块只新增内部包 `internal/automation/client`，不加第三方依赖。
- 不新增应用侧协议：界面工具只用 `internal/automation` 已有的 op（hello、windows、tree、find、count、wait、action、input、eval、screenshot、quit）。
- 应用一律后台启动：环境里 `TANGO_LAUNCH_BACKGROUND=1`；`app_start` 的 env 拒绝任何 `TANGO_` 开头的键；`dev` 任务也带 `TANGO_LAUNCH_BACKGROUND=1`；不提供前台启动。
- 根目录限制：工具参数里的路径解析（含 `filepath.EvalSymlinks`）后必须在 `-root` 内；例外只有 tan 自己的临时目录、Go 工具链与缓存；`app_attach` 的 token 文件路径不受限。
- 传输：默认 stdio；`-http` 只接受回环地址（`127.0.0.1`、`localhost`、`[::1]`），用 streamable HTTP，`Authorization: Bearer <token>` 常量时间比较，`Origin`/`Host` 只能是回环地址；无 `-token` 时随机生成并打印到 stderr。
- 不执行任意 shell 命令：工具只接受定义好的字段。
- 会话与任务属于服务器：服务器退出时停止它启动的所有任务和应用（`app_attach` 的只断开）。
- 只借鉴 Wails 的思路，不照搬代码。
- 提交作者固定 `tango <903300326@qq.com>`（设置 `GIT_AUTHOR_*`、`GIT_COMMITTER_*`），不加 Co-Authored-By。
- `tan help` 与子命令参数受 `cmd/tan/testdata/cli.golden` 约束：改动后 `cd cmd/tan && go test -run TestCLIGolden -update` 并审查 diff。
- 数值：任务、应用输出缓冲各保留最后 256 KiB；`job_status` 默认返回最后 200 行、最多 64 KiB；`tree` 默认最多 400 个节点；等待类工具默认超时 10 s、上限 120 s；`app_start` 启动等待默认 60 s、上限 300 s（含构建）。

## Review Focus

1. 根目录内的符号链接指向根目录外：路径应被拒绝，报错写明解析后的真实路径（Task 3 测试 `TestResolveRootSymlinkEscape`）。
2. 任务的孙进程（`go build` 的编译器、`tan dev` 拉起的应用）在 `job_stop` 或服务器退出后残留：应按进程组整体结束（Task 4 测试 `TestJobStopKillsGrandchild`）。
3. 应用在 `find`/`wait` 等待途中退出：工具应立即返回"应用已退出"加退出码和最后输出，而不是等到超时（Task 6 测试 `TestUIFindAppExitsMidWait`）。
4. 超大语义树或输出撑爆 MCP 响应：树按节点上限截断并注明"已截断 N 个节点"，输出按字节上限截断（Task 6 测试 `TestUITreeTruncates`）。
5. HTTP 模式被网页通过 DNS 重绑定访问：`Origin` 非回环时返回 403，缺令牌或令牌错误返回 401（Task 2 测试 `TestHTTPRejectsForeignOrigin`、`TestHTTPRequiresToken`）。
