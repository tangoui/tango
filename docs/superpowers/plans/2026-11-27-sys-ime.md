# sys/ime（macOS 输入法宿主）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Tango 应用可以通过公开包 `sys/ime` 在 macOS 上作为系统输入法运行，并且 `tan build` 能打出可安装的输入法包。

**Architecture:** 在 `internal/platform` 新增 `InputMethods` 接口。darwin 后端用 purego 在运行时注册 `TangoInputController`（`IMKInputController` 的子类）并启动 `IMKServer`，每个 controller 对应一个会话 id，回调通过 `InputMethodSink` 交给 `sys/ime`。`sys/ime` 把会话 id 包装成 `*Session`，在主线程调用应用的 `Handler`，并用 corehook.Guard 接住 panic。tan 根据 `macos.inputMethod` 往 Info.plist 写入 IMK 键。

**Tech Stack:** Go、purego/objc、InputMethodKit、Carbon TIS（仅冒烟脚本使用）。

**Spec:** `docs/superpowers/specs/2026-11-27-sys-ime-design.md`

## Global Constraints

- 只用 purego，不加 .m 文件，不要求 cgo。
- 控制器类名固定为 `TangoInputController`；默认连接名为 `<app id>_Connection`。
- 包 id 必须含 `.inputmethod.`，否则 `tan build` 报错。
- `sys/ime` 在 `api/tiers.txt` 登记为 `experimental`，并补上 golden 文件 `api/go/sys_ime.txt`。
- 非输入法应用的行为（激活策略、Info.plist）一字不变。
- 所有回调都在主线程执行；回调里的 panic 被接住后按"未处理"返回 false。
- 提交身份 `tango <903300326@qq.com>`，不加 Co-Authored-By。推送前检查：gofmt -l（含带构建标签的文件）、交叉 vet（GOOS=windows/linux）、`go run ./internal/cmd/apitxt -check`、`cmd/tan` 用 GOWORK=off 单独编译。

## Review Focus

1. 宿主应用里组字时按 Cmd+快捷键（如 Cmd+A）：应该先把组字原样上屏，再放行快捷键，不能吞键。→ Task 3 的 `TestIMEKeyModifiers` 加上 Task 5 的引擎测试。
2. 组字中含 BMP 以外的字符（emoji）：传给系统的光标位置按 UTF-16 计算，不能越界。→ Task 3 的 `TestUTF16Cursor`。
3. Handler.Key 里发生 panic：宿主不能崩，这个键放行。→ Task 4 的 `TestKeyPanicPassesThrough`。
4. 在 Windows、Linux 上调用 `ime.Serve`：返回 ErrUnsupported，不能 panic。→ Task 4 的 `TestServeUnsupported`。
5. 同一个进程里调用两次 `Serve`：第二次返回 `ErrServing`。→ Task 4 的 `TestServeTwice`。

### Task 3: platform 接口与 darwin 的 IMK 实现

**Files:**
- Modify: `internal/platform/ext.go`（新增接口）
- Create: `internal/platform/darwin/inputmethod.go`、`internal/platform/darwin/inputmethod_keys.go`
- Test: `internal/platform/darwin/inputmethod_test.go`
- 其他后端不实现该接口（sys/ime 通过类型断言判断，断言失败即 ErrUnsupported）。

**Interfaces（Produces，Task 4 使用）：**

```go
type IMEKey struct{ Code, Text string; Shift, Ctrl, Alt, Meta bool }
type InputMethodSink interface {
	IMEKey(session uint64, k IMEKey) bool
	IMEActivate(session uint64)
	IMEDeactivate(session uint64)
	IMECommitComposition(session uint64)
	IMEEnd(session uint64)
}
type InputMethods interface {
	ServeInputMethod(connection string, sink InputMethodSink) error // 主线程调用
	IMESetComposition(session uint64, text string, cursor int)     // cursor 按 rune 计，"" 清除
	IMECommit(session uint64, text string)
	IMECaret(session uint64) Rect
	IMEClientApp(session uint64) string
}
```

darwin 端的做法：`dlopen` InputMethodKit；注册 `TangoInputController`，覆盖 `initWithServer:delegate:client:`（分配会话 id 并记下 controller）、`handleEvent:client:`、`activateServer:`、`deactivateServer:`（先回调 sink，再调 super）、`commitComposition:`、`dealloc`（先 IMEEnd，再调 super）。重复调用 `ServeInputMethod` 返回错误。上屏和组字发给 `[controller client]`：用 `insertText:replacementRange:`，以及 `setMarkedText:selectionRange:replacementRange:`，替换范围传 `{NSNotFound,0}`。Caret 用 `attributesForCharacterIndex:0 lineHeightRectangle:` 拿到矩形后，借助 `primaryHeight()` 翻转为左上原点。ClientApp 取 `[client bundleIdentifier]`。只处理 keyDown 事件，其余直接返回 false。

- [ ] **Step 1:** 写纯函数测试。`TestIMEKey`：`imeKey(0x00, "a", "a", 0)` 得到 `{Code:"KeyA", Text:"a"}`；`imeKey(0x31, " ", " ", 0)` 的 Code 为 "Space"；0x24→"Enter"，0x33→"Backspace"，0x35→"Escape"，0x30→"Tab"，0x7E→"ArrowUp"；Shift+0x00 带 chars "A" 时 Text 为 "A"、Shift 为 true；数字键 0x12 的 Code 为 "Digit1"。`TestIMEKeyModifiers`：flags 含 1<<20 时 Meta 为 true，含 1<<18 时 Ctrl 为 true，含 1<<19 时 Alt 为 true。`TestUTF16Cursor`：`utf16Offset("你好", 2)==2`，`utf16Offset("a😀b", 2)==3`，cursor 越界时取全长，负数时取 0。
- [ ] **Step 2:** 运行 `go test ./internal/platform/darwin -run 'IMEKey|UTF16'`，应为 FAIL。
