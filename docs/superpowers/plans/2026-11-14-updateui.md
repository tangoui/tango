# 默认更新界面（updateui）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新包 `service/updater/updateui`：应用一行 `updateui.Start` 就有现成的更新窗口（后台检查、更新说明、下载进度、重启安装、跳过此版本），WebView 应用和 Go 自绘应用都能用。

**Architecture:** 纯逻辑与界面分开：`state.go`（`updateui.json` 持久化）、`model.go`（界面状态机，不依赖 ui，可单测）、`flow.go`（驱动 `*updater.Updater` 的检查/下载/安装，串行化，事件写入 model）、`view.go`（`ui` 画 model 的当前状态，`ui.Driver` 无头测试）、`window.go` + `updateui.go`（经 `app.Post` 在主线程用 `uihost.Open` 开唯一窗口；`Start` / `CheckNow` 入口）。`service/updater` 不改。

**Tech Stack:** Go；`github.com/tangoui/tango/service/updater`、`ui`、`uihost`、`i18n`；测试用 `ui.Driver`、`internal/platform/fake/faketest`、`net/http/httptest` + `updater.GenerateKey` / `updater.SignManifest`。

**Spec:** `docs/superpowers/specs/2026-11-14-updateui-design.md`

## Global Constraints

- 新包路径 `service/updater/updateui`；在 `api/tiers.txt` 加精确行 `service/updater/updateui experimental`（放在 `service/...` 之前的稳定区块之外，写到 "# Experimental." 区块），`go run ./internal/cmd/apitxt -check` 必须通过。
- 不修改 `service/updater` 下任何现有文件。
- 后台检查间隔默认 24h（`Interval` 0 = 24h，<0 关闭后台检查）；首次检查延迟默认 30s（`FirstDelay` 0 = 30s）。
- 状态文件名 `updateui.json`，目录规则照搬 `service/updater/state.go:70-84`：显式 `Updater.StateDir`，否则 `<os.UserConfigDir()>/tango-updater/<safeName(AppID 或可执行文件名去扩展名)>`，`safeName` 保留 `. - _ a-z A-Z 0-9`，其余替换为 `_`。目录权限 0o700。
- 内置文字语言：`en`、`zh-CN`、`zh-TW`、`ja`（与 `i18n.Builtin` 一致），其他语言回退 `en`；跟随 `i18n.Locale()`，经 `i18n.OnChange` 实时更新；`Options.Text` 非 nil 时整体覆盖。
- 窗口约 480×360，标题 zh-CN "软件更新" / en "Software Update"；每个 `*tango.App` 至多一个更新窗口。
- `uihost.Open`、`Surface.Show/Focus/Close` 只在主线程调用（经 `app.Post` 或 `tango.Await`）；跨 goroutine 刷新只用 `Runner.Invalidate`。
- 每个 `*updater.Updater` 同时至多一个检查或下载（`*Updater` 非并发安全）。
- 安装按钮只在 `runtime.GOOS` ∈ {darwin, windows, linux} 时出现。
- 提交信息不加 Co-Authored-By；提交时只提交本任务列出的文件（`git commit --only -- <files>`，并先确认这些文件没有他人改动）。

## Review Focus

1. **"跳过此版本"之后，后台检查又找到同一版本**：不得弹窗；找到更新的版本时照常弹窗 → Task 4 测试 `TestBackgroundSkipsSkippedVersion`。
2. **后台检查时没有新版本 / 出错**：不得打开窗口；`CheckNow` 时才显示"已是最新"或错误 → Task 4 `TestBackgroundSilentWhenUpToDateOrError`、Task 6 `TestCheckNowShowsUpToDate`。
3. **检查进行中又触发 `CheckNow`（或计时器）**：不得对同一 `*Updater` 并发调用 `Check`/`Download` → Task 4 `TestNoConcurrentCheck`（-race 下跑）。
4. **"下次启动时安装"记录的 Payload 文件已被删除或版本不再比当前新**：丢弃记录，不弹"已下载"窗口 → Task 2 `TestPendingDiscardedWhenMissingOrStale`、Task 6 `TestStartOffersDownloadedUpdate`。
5. **`Start` 与 `CheckNow` 交替、重复调用**：`u.OnEvent` 只包一层，应用原有回调每个事件只被调用一次；`stop()` 后还原为应用原值 → Task 6 `TestOnEventWrappedOnce`。

### Task 3: 界面状态机（model）

**Files:**
- Create: `service/updater/updateui/model.go`
- Test: `service/updater/updateui/model_test.go`

**Interfaces:**
- Produces:
  - `type phase int`，常量 `phaseIdle, phaseChecking, phaseAvailable, phaseDownloading, phaseReady, phaseDownloaded /* 下次启动时询问 */, phaseError, phaseUpToDate, phaseRolledBack`
  - `type model struct`（导出给同包，字段受 `mu sync.Mutex` 保护）：`phase phase; current string; rel *updater.Release; patch bool; done, total int64; err error; unsupported bool; manual bool; onChange func()`
  - `func (m *model) snapshot() view`，`type view struct`：上述字段的拷贝（`err` 转为 `errText string`，`unsupported` 原样），界面只读 `view`。
  - `func (m *model) set(fn func(*model))`：加锁执行 fn，解锁后调用 `onChange`（若非 nil）。
  - `func (m *model) applyEvent(e updater.Event)`：
    - `EventChecking` → `phaseChecking`
    - `EventAvailable` → `phaseAvailable`，`rel = e.Release`
    - `EventUpToDate` → `phaseUpToDate`
    - `EventDownloading` → `phaseDownloading`，`patch = e.Patch`，`done, total = 0, -1`
    - `EventProgress` → `done, total = e.Done, e.Total`（仅在 `phaseDownloading`）
    - `EventPatchFailed` → 保持 `phaseDownloading`，`patch = false`（不进入错误）
    - `EventVerified` → `phaseReady`
    - `EventError` → `phaseError`，`err = errors.New(e.Error)`
    - `EventReady` → 不改 phase（安装后由调用方退出应用）
  - `func (v view) progress() float64`：`total > 0` 时 `float64(done)/float64(total)`（夹到 [0,1]），否则 -1（不确定进度）。

### Task 4: 流程驱动（检查 / 下载 / 安装，串行化，后台调度）

**Files:**
- Create: `service/updater/updateui/flow.go`
- Test: `service/updater/updateui/flow_test.go`（含本地发布服务器测试夹具）

**Interfaces:**
- Consumes: Task 2 `loadState/saveState/persisted`、Task 3 `model`。
- Produces:
  - `type flow struct`：`u *updater.Updater; m *model; busy atomic.Bool; cancel context.CancelFunc（下载用，受锁）; st persisted（受锁）; laterThisRun string; show func(manual bool) /* 请求打开或前置窗口，Task 6 注入 */; quit func() /* 退出应用，Task 6 注入 */`
  - `func newFlow(u *updater.Updater, m *model) *flow`
  - `func (f *flow) check(ctx context.Context, manual bool)`：`busy` 已占用时：`manual` 为真则只调用 `f.show(true)` 后返回，否则直接返回。否则调用 `u.Check(ctx)`：
    - 返回 `(nil, nil)`：model→`phaseUpToDate`；只有 `manual` 时 `show(true)`。
    - 返回 rel：若 `!manual && (rel.Version == st.Skipped || rel.Version == laterThisRun)` 则不显示；否则 model→`phaseAvailable` 并 `show(manual)`。
    - 返回错误：model→`phaseError`（`errors.Is(err, updater.ErrUnsupported)` 时 `unsupported=true`）；只有 `manual` 时 `show(true)`。
    - 结束时 `st.LastCheck = time.Now()` 并 `saveState`。
  - `func (f *flow) download()`：在新 goroutine 里 `u.Download(ctx, rel, "")`（`ctx` 可被 `cancelDownload` 取消）；成功后保存 `*updater.Payload` 到 `f.payload`，model→`phaseReady`；失败且非取消→`phaseError`；取消→`phaseAvailable`。`busy` 期间不允许再次 `check`。
  - `func (f *flow) cancelDownload()`
  - `func (f *flow) skip()`：`st.Skipped = rel.Version`，保存，关闭窗口由调用方处理。
  - `func (f *flow) later()`：`laterThisRun = rel.Version`。
  - `func (f *flow) restartNow() error`：`u.Apply(f.payload)`；nil → 清 `st.Pending` 并保存，然后 `f.quit()`；`errors.Is(err, updater.ErrUnsupported)` → model→`phaseError`、`unsupported=true`；其他错误→`phaseError`。
  - `func (f *flow) installNextLaunch()`：`st.Pending = &pendingPayload{Version: rel.Version, Path: payload.Path, Patched: payload.Patched, Release: rel}`，保存。
  - `func (f *flow) schedule(ctx context.Context, interval, firstDelay time.Duration)`：goroutine：等待 `max(firstDelay, LastCheck+interval-now)`（不早于 firstDelay）后 `check(ctx,false)`，之后每 `interval` 一次；`ctx` 取消即退出；`interval < 0` 时不启动。计时用可替换的 `var after = time.After`（测试注入）。

**Files:**

- Consumes: Task 1 `*Strings`、Task 3 `view`/`phase`。

  - `type actions struct { skip, later, install, cancel, restartNow, installNextLaunch, retry, close, openDownloadPage func() }`
  - `func page(m *model, s func() *Strings, a actions) func(*ui.Context)`：返回 `ui` 页面函数，每帧读 `m.snapshot()` 与 `s()` 渲染：
    - `phaseAvailable`：标题 `s.Title`；`fmt.Sprintf(s.NewVersion, rel.Version, current)`；有 `PubDate` 时 `fmt.Sprintf(s.Released, date)`；`rel.Notes` 用 `ui.Markdown` 放在可滚动区域；按钮 `s.Skip`、`s.Later`、`s.Install`（Primary）。`runtime.GOOS` 不在 {darwin,windows,linux} 时不显示 `s.Install`。

    - `phaseUpToDate`：`fmt.Sprintf(s.UpToDate, current)`；按钮 `s.Close`。
    - `phaseRolledBack`：`fmt.Sprintf(s.RolledBack, current)`；按钮 `s.Close`。
    - `phaseChecking`：`ui.Spin(c)` 加一行检查中文字（在 `Strings` 中加字段 `Checking`，Task 1 的字段表与四种语言同步加上）。
