# 组件总览

Tango 自绘 UI（`github.com/tangoui/tango/ui`）的全部组件，按通用、布局、导航、数据录入、数据展示、反馈、图表和移动端分组，与左侧导航一致。每个组件有 Ant Design、Element Plus、shadcn/ui 三套风格和深浅色，组件页里可以直接切换主题、操作在线示例并查看 Go 源码。

第一次使用请先看 [自绘 UI 入门](/guide/ui)；想对比全部场景，打开 [在线演练场](/components/playground)。
