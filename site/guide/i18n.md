# 多语言

`github.com/tangoui/tango/i18n` 提供三件事：读取用户的**系统语言**、维护一个应用可覆盖的**当前语言**、一个支持具名参数和 CLDR 复数类别的**文案目录**。原生菜单的标准项和对话框默认按钮也按当前语言显示。

## 文案目录

```
locales/
├── en.json
└── zh-CN.json
```

```jsonc
// locales/en.json
{
  "hello": "Hello, {name}!",
  "files": { "one": "{count} file selected", "other": "{count} files selected" }
}
// locales/zh-CN.json
{
  "hello": "你好，{name}！",
  "files": { "other": "已选择 {count} 个文件" }
}
```

```go
//go:embed locales
var locales embed.FS

if err := i18n.Load(locales, "locales"); err != nil { log.Fatal(err) }
i18n.T("hello", "name", "Tom")   // 你好，Tom！
i18n.N("files", 3)               // 已选择 3 个文件（自动带 {count}）
```

- 每个文件是扁平的 JSON 对象，文件名就是语言标签（也接受 `zh_CN.json`）；复数项的值是以 CLDR 类别（`zero`/`one`/`two`/`few`/`many`/`other`）为键的对象，必须有 `other`。
- 参数是名/值成对的可变参数；`{name}` 没有对应参数时原样保留；<span v-pre>`{{`、`}}`</span> 表示字面花括号。
- 回退顺序：当前语言 → `en` → key 本身。开发构建（`-tags tango_dev`，`tan dev`）里每个缺失的 key 只警告一次，默认构建不输出。
- 同一语言可以多次 `Load`，后加载的覆盖先加载的。
- 内置复数规则覆盖中日韩（只有 `other`）、英德等（`one`/`other`）、法葡等（0 和 1 为 `one`），其他语言用 `i18n.RegisterPluralRule` 注册。

## 系统语言与当前语言

```go
i18n.Preferred()     // 系统首选语言，BCP 47，按用户偏好排序，例如 [zh-Hans-CN en-US]
i18n.Supported()     // 已加载目录的语言；没加载时为内置的 en、zh-CN、zh-TW、ja
i18n.Locale()        // 当前语言：SetLocale 的覆盖值，否则 Match(Preferred(), Supported())
i18n.SetLocale("ja") // 应用内切换；"" 恢复跟随系统
cancel := i18n.OnChange(func(loc string) { rebuildUI() })
```

匹配规则：完全相同 → 中文按书写系统分流（`zh`、`zh-CN`、`zh-SG`、`zh-Hans*` 归简体；`zh-TW`、`zh-HK`、`zh-MO`、`zh-Hant*` 归繁体，**简繁不互相替代**）→ 同语言同地区 → 同语言。都不中时用 `en`。

| 平台 | 系统语言来源 |
|---|---|
| macOS | `NSLocale preferredLanguages` |
| Windows | `GetUserPreferredUILanguages` |
| Linux | `LANGUAGE`、`LC_ALL`、`LC_MESSAGES`、`LANG` |
| iOS / Android | 尚未接入（计划中）；目前回落到环境变量 |

不需要 `tango.App` 就能用（单元测试、命令行工具里也可以）；Tango 目前不监听系统语言设置的变化，需要时调用 `i18n.Refresh()`。

## 原生菜单与对话框

菜单标准项（`menu.AppMenu`、`EditMenu`、`Quit`……）和对话框的默认按钮在 en、zh-CN、zh-TW、ja 四种语言里按各平台官方用词显示（macOS 用苹果的用词，Windows 用微软的，Linux 用 GTK 的并带助记符）。

注意：

- `SetLocale` 之后已经设置的菜单不会自动刷新，请重新 `menu.SetAppMenu` 或调用 `Menu.Update()`。
- macOS 上有几项由 AppKit 自己维护（撤销/重做的动态标题、系统插入的「自动填充」「开始听写」等），跟随应用包的本地化声明而不是 Tango；裸二进制（`go run`）里这些项显示英文。

## 页面与自绘 UI

- WebView 页面的文案由前端自己管理（可以用任意前端 i18n 库）；需要和 Go 保持一致时，把 `i18n.Locale()` 通过绑定方法或事件交给页面。
- 自绘 UI 组件内置文案（日期选择、分页、空状态等）有自己的语言表：`if l, ok := ui.LocaleByCode(i18n.Locale()); ok { ui.SetDefaultLocale(l) }`。让它自动跟随 `i18n.Locale()` 的工作已在计划中。

示例：`examples/i18n-demo`（`-print` 只打印语言，`-lang ja` 覆盖语言）。
